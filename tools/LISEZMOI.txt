QuickWheel — roue de raccourcis pour Windows
============================================

Installation : aucune. Lance QuickWheel.exe (Windows 10/11, 64 bits).

Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur »
(l'exe n'est pas signé) : clique « Informations complémentaires » puis « Exécuter quand même ».

Utilisation
- Appuie sur ² (sous Échap, clavier AZERTY) pour ouvrir la roue.
- Maintiens ², vise une case, relâche : le raccourci s'exécute.
- Appui bref sur ² : la roue reste ouverte, clique sur une case.
- Clique sur le logo au centre de la roue pour ouvrir les réglages.
- QuickWheel reste dans la zone de notification (en bas à droite, près de l'heure) :
  clic droit sur l'icône pour les réglages ou pour quitter.

Dans les réglages, coche « Lancer avec Windows » pour qu'il démarre tout seul.
Ta configuration est enregistrée dans %APPDATA%\QuickWheel\config.json.
